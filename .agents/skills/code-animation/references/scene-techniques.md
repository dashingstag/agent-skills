# Choosing and checking scene techniques

| Request | Start from | Look for in review |
|---|---|---|
| Camera, parallax, edits | `templates/project/lib/motion.py`; see [motion-study](https://github.com/dashingstag/agent-skills/tree/main/demos/motion-study) | Place transforms on oversized layers or leave overscan. Sample both sides of each shot boundary; retain the action's direction and phase across a cut. |
| Typography, charts, UI | `templates/browser/`; see [backends](backends.md) and [browser-explainer](https://github.com/dashingstag/agent-skills/tree/main/demos/browser-explainer) | Use a fixed viewport, wait for fonts, check final labels at playback size. Real recordings are footage; scripted UI is a browser render. For interactive delivery, test input and reduced motion in the actual browser. |
| Cutouts and walk cycles | `lib/rig.py`, `lib/model_sheet.py`; see [cutout-walk](https://github.com/dashingstag/agent-skills/tree/main/demos/cutout-walk) | Approve original silhouettes, joint centers, scale, colors and facial feature placement. Check front/mirror/back views, facial expressions, foot contact and hand placement across movement and cuts. |
| Social/loop | `still --safe-area` and `loop`; see [vertical-loop](https://github.com/dashingstag/agent-skills/tree/main/demos/vertical-loop) | Use the target platform's UI exclusion zones when known. 5% and 10% guides are starting points. Render `0..N-1` with period `N`, don't duplicate frame 0 as frame N−1. Check final-to-first motion, not just mean seam error. |
| Dialogue | External WAV, timed transcript and `lib/rig.py`; see [talking-head](https://github.com/dashingstag/agent-skills/tree/main/demos/talking-head) | Align words and mouth poses against the actual WAV; compare onsets, rests, and final syllables and inspect the delivered captions. Use authorized audio. |
| Particles | `lib/effects.py`; see [weather-effects](https://github.com/dashingstag/agent-skills/tree/main/demos/weather-effects) | Give emitters independent seeds, then review a consecutive-frame strip, compare hashes between worker counts, and check birth and fade behavior. |
| Photo/footage | `lib/footage.py`; see [backends](backends.md) and [tracked-plate](https://github.com/dashingstag/agent-skills/tree/main/demos/tracked-plate) | Record provenance, probe source FPS and duration, set conversion deliberately and measure whether the overlay follows reference positions after conversion. |
| 3D or mixed media | `templates/blender/`; see [backends](backends.md) and [blender-composite](https://github.com/dashingstag/agent-skills/tree/main/demos/blender-composite) | Verify transparent PNGs over light and dark backgrounds, hold canvas and FPS fixed, and inspect depth/lighting and the exported 2D composite. |

## Timing conventions

- Keyframes accept strictly increasing timestamps and clamp at the ends. Camera depth controls the amount of translation and zoom; shake derives from the supplied frame phase. For a wipe or dissolve, budget the overlap explicitly inside a shot and evaluate the two local renders at matching timeline positions. For a hard cut, match direction, speed and silhouette at the action frame; `transition(..., "cut-on-action", action=.5)` chooses the incoming view at the specified normalized time without blending.
- Caption cues are global, with end-exclusive frame ranges. Viseme keys are local to a shot, step rather than interpolate and must start at frame 0. Spot-check speech onset and end with a waveform/silence detector; manual visemes are intentionally approximate, not an automatic phoneme aligner.
- Use `still SHOT --strip START:STOP` for consecutive sample frames. Make a separate sparse sheet for layout. Render at two worker counts for stateful-looking effects and compare decoded frame hashes.
