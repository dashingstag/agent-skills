# agent-skills

Personal skills for Devin, Claude Code, Codex and GitHub Copilot sessions.
`skills/` is the canonical source; discovery copies for each client are
generated by `tools/sync_skills.py`.

## Install

| Client | Command / path |
|---|---|
| Devin CLI / Desktop | `devin plugins install dashingstag/agent-skills` → `/agent-skills:<skill>` |
| Claude Code | `/plugin marketplace add dashingstag/agent-skills` then `/plugin install agent-skills@agent-skills` |
| Codex | `python tools/sync_skills.py --install` → `~/.codex/skills` (plus the other clients) |
| GitHub Copilot | `gh skill` install from this repo, or `--install` → `~/.copilot/skills`; in a checkout, `.github/skills` is discovered automatically |

`--install` publishes into `~/.agents`, `~/.claude`, `~/.codex` and
`~/.copilot` skill folders at once — one command, every client covered.

## Skills

| Skill | Purpose |
|---|---|
| `hapiv` | Implement a change while verification runs as parallel asynchronous jobs on whatever execution harness is available, then repair failures and aggregate one evidence-backed verdict (Harness-Agnostic Parallel Implementation and Verification). |
| `railway-deploy` | Prepare and check a Node/TypeScript repo (including npm-workspace monorepos) so it deploys to Railway as a single service. |
| `teardown-audit` | Break down any codebase into a cited, scored audit — pipeline decomposition, five-level health rubric, evidence on every verdict — emitted as one offline HTML report with pipeline / issue-tracker / explainer tabs. |

## Layout

```
skills/<name>/SKILL.md      # canonical skill sources
.devin-plugin/plugin.json   # Devin plugin manifest
.claude-plugin/*.json       # Claude plugin + marketplace manifests
.agents|claude|github/skills/  # generated discovery copies (don't edit)
tools/sync_skills.py        # refresh copies, --check, --install to home dirs
```

New skills go in their own `skills/<name>/` directory following the
[SKILL.md format](https://docs.devin.ai/cli/extensibility/skills/creating-skills),
then `python tools/sync_skills.py` refreshes every client's copies.
