# Estuary Log

The plate is original procedural artwork generated by `scene.py`; no external images or footage were used. It is encoded at 30 fps with BT.709 signaling; the overlay uses five reference positions on the 24 fps timeline. Mismatched duration, rate or dimensions cause errors instead of an implicit trim. Tracking is interpolated from known positions, not automatic object detection.

Generate the render and contact sheets locally with the commands below. Share media as attachments or release assets; do not commit it.

From this demo directory, set the template path and use a Python environment with the project template's requirements:

```sh
T=../../skills/code-animation/templates
A=$T/project/tools/animate.py
PYTHONPATH="$T/project" python scene.py
python "$A" validate
python "$A" render --jobs 2
python "$A" assemble --out dist/tracked-plate.mp4
python "$A" verify dist/tracked-plate.mp4
python "$A" still track --sheet
```
